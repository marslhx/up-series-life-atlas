# 人生七年：十次相见，十四种人生

这是一个围绕英国纪录片《人生七年》（*Up Series*）制作的互动纪念网站。网站以十四位受访者的十个人生阶段为基础，提供人生全景、条件筛选、人物比较、问题回声与创作手记等观看方式。

## 在线访问

GitHub Pages：<https://marslhx.github.io/up-series-life-atlas/>

## 项目说明

- 人物经历按来源可靠性分层整理；信息不完整不等于相关事件没有发生。
- 人物比较中的轨迹与分类属于编辑性阅读，不是人生价值或幸福程度的评分。
- 节目画面及相关影像的权利归原权利人所有，本项目用于非商业性的文化回顾与讨论。
